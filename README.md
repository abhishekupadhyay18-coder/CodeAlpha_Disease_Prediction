# Disease Prediction from Medical Data

A supervised classification project using the Breast Cancer Wisconsin dataset bundled with scikit-learn.

### Workflow
Dataset → train/test split → feature scaling → Logistic Regression → evaluation.

### Evaluation
Accuracy, Precision, Recall, F1-score, ROC-AUC, confusion matrix and ROC curve.

### Run
```bash
pip install -r requirements.txt
cd src
python disease_prediction.py
```

The project is for educational use only and must not be treated as a clinical diagnostic system.
